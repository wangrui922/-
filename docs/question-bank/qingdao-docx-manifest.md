## 六、已拍板决策（2026-08-04 · 主理人齐活林代老板拍板）

> 以下 3 项原列「待确认」，现由交付总监在老板授权下直接定调，模块启动即按此执行。

### ① 答案 + 解析：全入库（题干 + 答案 + 解析）
- **决定**：题干、标准答案、解析三者全部入库；`analysis`(解析) 允许为空（原书只有答案无解析时留空，后续可让 AI 补）。
- **理由**：本产品是「错题诊断 → 薄弱点 → 定向练习」闭环。练习环节系统必须知道正确答案才能判分；AI 导师要基于解析生成引导式讲解。若只存题干，AI 每次都得重新算答案——小学题格式杂、易错，且白白耗 token。所以答案+解析是必备底料，哪怕 UI 暂不展示给学生。

### ② 知识点标签：挂，但走「自动打标 + 待复核」
- **决定**：每题带 `knowledge_point_id`（可空，对应现有 `knowledge_points` 表）+ `kp_verified`(默认 false)。入库时用 AI/规则做 best-effort 自动打标；未确认(`kp_verified=false`)的题目**暂不参与**薄弱点统计，待人工复核后再启用。
- **理由**：错题归因到知识点 → 喂给掌握度引擎 → 生成针对性练习，这是产品的核心闭环，没有标签就转不起来。但原 docx 没有显式知识点标注，是隐含在内容里的，所以不追求一次性标准，先「自动打标 + 标记未确认」，保证闭环能跑、又不让脏标签污染统计。

### ③ 多版本统一：青岛版 + 苏教版 进同一题库，用 `edition` 区分
- **决定**：青岛版与苏教版期末卷**纳入同一个题库**，用 `edition` 字段区分（再补 `source_type`：衔接 / 期末）。青岛版学生只练青岛版对齐题，苏教版走苏教版对齐，互不串。
- **理由**：一个库多版本，覆盖年级最广、维护成本最低。同目录的苏教版 5/6 年级期末卷是优质种子（覆盖期末题型），不应浪费。
- **后续动作（已完成）**：苏教版期末卷 docx 已于 2026-08-04 当晚登记，详见文末**附录 A**。

### A.3 结构画像（已抽样核对）

- **丛书**：少而精·期末活页卷 / 期末活页卷（配苏教版第二学期）
- **结构特点（与青岛版关键差异）**：
  - **A 组（摸底诊断卷）是「正文 / 答案 双 docx 分离」**——正文 docx 只含题目，答案在独立 docx（"五年级数学·参考答案"），按「一、二、三…」大题号 + 小题序号一一对应。入库时须按卷号把答案配对回原题（这是与青岛版最大的不同，青岛版是题干答案同册）。
