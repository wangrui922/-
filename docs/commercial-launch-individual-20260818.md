## 0. 先说清楚的三个现实约束

1. **备案是绕不开的坎（仅限中国大陆稳定访问）**
   EdgeOne 默认 `*.edgeone.cool` 域名在中国大陆访问会因"未备案"被限（401/失效）。
   要稳定公开访问，必须 **自定义域名 + ICP 备案**。无备案 = 只能给临时预览链接（会过期）。

2. **个人不能收费**
   个人 ICP 备案的性质是"非经营性"，法律上**不能**用来做收费业务。
   想收费，必须升级为「个体工商户 / 企业」备案。

3. **60 人规模很小，几乎不花钱**
   EdgeOne Makers 免费额度（静态托管 + 云函数调用 + Blob 存储）对个人项目通常绰绰有余。
   60 人 × 日均约 70 次请求 ≈ 12.6 万/月，远低于免费上限。
   **真正的年成本只有"域名 ¥60"这一项。**

## 2. 推荐路线：**A 起步 → B 升级**（成本最低、路径最顺）

先以"个人、免费内测"把 60 人跑起来验证产品，同时并行办个体户执照；
备案下来后无缝升级到"能收费"的 B 路线。全程不花冤枉钱。

### Phase A：免费内测 60 人（现在就能启动，成本仅域名）

1. **买域名**：腾讯云/阿里云，¥50–100/年，建议 `.cn`（备案顺畅）。
2. **个人网站备案**：腾讯云备案系统提交，免费，1–3 周；需身份证 + 真实性核验。
   - 备案类型：个人；网站性质：非经营性；接入商：腾讯云/EdgeOne。
3. **备案期间（我来做）**：搭好 Makers 项目骨架（前端 + /api 云函数 + Blob 进度存储），本地 + dev 验证。
4. **备案号下发**：Makers 绑定自定义域名 + 免费 SSL → 拿到**稳定公开 URL**。
5. **60 人免费内测**：进度跨手机/平板/电脑同步（Blob）。

> 成本：¥60/年域名 + ¥0 备案 + ¥0 Makers 免费额度。

### Phase B：要收费时升级（仍低成本）

1. **办个体工商户营业执照**：本地"一网通办"，免费或 ¥0–300，约 1 周。
2. **备案主体升级**：由个人变更为个体户（性质改经营性）。
3. **开通微信支付**：个体工商户可开商户号，费率约 0.6%。
4. **前端登录换微信登录 + 支付**。

> 成本：+¥0 执照 + ¥0 备案 + 0.6% 交易手续费。

## 3. 技术落地（Makers 项目结构）

- **前端**：现有 Vue 照旧，Makers 托管静态（同域免 CORS）。
- **/api**：FastAPI 搬进 `cloud-functions/api/`（Makers 原生支持 Python FastAPI）。
- **题库**：1735 题 SQLite 只读打包进云函数（读题/抽题/判题）。
- **进度 / 错题**：改用 **Blob 存储**（替换前端 localStorage + 本机 SQLite），实现跨端同步。
- **登录**：Phase A 先用「手机号 + 验证码」（已有 13988491963 / 000000 验证链路）；
  Phase B 换微信登录 + 支付。
